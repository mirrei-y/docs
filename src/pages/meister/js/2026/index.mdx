## はじめに
JavaScript コースをご選択いただきありがとうございます。このコースでは、主に Web アプリケーション制作の基礎を学ぶことを目的としています。

### 対応している環境

この講義は、Windows・macOS・Linux に対応しています。

講義は Windows と Visual Studio Code を使用する前提で作成されていますが、OS 依存のソフトウェア・機能を使用しません。
macOS や Linux を使用される方は適宜読み替えてください。

### JavaScript とは
JavaScript とは、Web ページに動きをつけるために作成された「スクリプト言語」と呼ばれるプログラミング言語の一種です。

今では拡張に拡張を重ね、本来の用途である Web ページ以外にも、サーバーで動くプログラムの作成、デスクトップ・スマートフォンで動くアプリケーションの作成など、様々な用途に使用できます。

<Tips>
JavaScript は、Java とは全く異なる言語です。

JavaScript を Java と省略することは誤解を生みますので、なるべく行わないようにしましょう。
</Tips>
