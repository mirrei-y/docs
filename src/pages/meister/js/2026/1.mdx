## ランタイム
### JavaScript を動かせる環境
プログラミング言語は、実行する方式によって**コンパイル方式**と**インタプリタ方式**という2種類の方式に分類され、JavaScript は後者のインタプリタ方式に分類されます。

それぞれメリットとデメリットがあるのですが、後者は特に**プログラムを実行するためのプログラム**が必要です。このプログラムのことを、**ランタイム**と呼びます。

本講義では、今あなたがこの Web ページを閲覧しているブラウザと、Node.js と呼ばれる、サーバープログラムを作成することを目的に作成されたランタイムを使用します。

ブラウザは、Web ページの構成を決定する HTML という言語を読み込み、それに基づき Web ページを表示します。

HTML には、そのページで動作する JavaScript プログラムを埋め込むことができます。
簡単に JavaScript を実行する方法として、このプログラムを埋め込む手法が挙げられます。

また、一般的なブラウザではコンソールから JavaScript を直接実行することもできます。

## 基本構文
実際にプログラミングを学ぶ前に、いくつかの前提知識をつけておきましょう。

### 式と文
現代のプログラミング言語は、いくつかの**文**を構成することによってコーディングすることが多いです。
JavaScript も例外ではなく、文によってプログラムを構成します。

その文を区切るために、JavaScript ではセミコロンを使用します。

```
何かの処理;
何かの処理;
何かの処理;
```

逆に、文ではないものには式などが挙げられます。

```js
1 + 1
```

`1 + 1` は式です。
それを明示するために、本講義では式単体を説明するときにはセミコロンを使用しません。

<Tips>
式は文とは異なります。しかし、式は文にすることができます。これを**式文**といいます。

例えば、以下は式と式文です。どちらも JavaScript で有効な構文です。
```js
1 + 1
1 + 1;
```
</Tips>

### コメント

コメントは、プログラムで無視される行・あるいは範囲のことです。
1行をコメントにするには、以下のように記述します。

```js
何かの処理... // ここからがコメント
```

このWebページでは、コードブロックの中で文字が灰色になっている部分がコメントです。

また、複数行や任意の範囲をコメントにすることができます。

```js
.../* ここから
ここも
さらにここも
ここまでコメント */...

.../* ここがコメント */...
```

本講義では、出力結果の説明、あるいは処理の説明などにコメントを使用します。

## 型の概念
プログラムでは、文字列や数値など、様々な値を扱います。

しかし、文字列と数値はプログラムにとって異なる概念のものです。プログラムでは、それらを分けて考える必要があります。この分けられたグループを**型**と呼んでいます。

### 型の種類
JavaScript には、以下のような型があります。
- 数値型 (number)
    ```js
    1
    2
    3
    100
    -345.678
    Infinity
    ```
- 文字列型 (string)
    ```js
    "Hello World!"
    ""
    ```
- ブーリアン型 (boolean)
    ```js
    true
    false
    ```
- undefined 型
    ```js
    undefined
    void 0
    ```
- null 型
    ```js
    null
    ```
- BigInt 型
- Symbol 型
- オブジェクト型
    - オブジェクト
    - 配列
    - 関数
    - クラス

### 数値型・文字列型
特筆すべきことはありませんが、文字列型については演算子の一つである `+` を使用して、文字列を連結することができます。
詳しくは後述します。

### ブーリアン型
ブーリアン型とは、真理値の「真」と「偽」をとる型です。

例えば、第2回で説明するif文（比較）などでは、このブーリアン型を使用して比較が行われます。

```js
const isWeekend = day === "Saturday" || day === "Sunday"; // ここはブーリアン型で、true もしくは false が入る
if (isWeekend) {
    何かの処理;
}
```

<Info>
`===` は、比較演算子の一種です。
詳しくは後述します。
</Info>

## 変数

プログラミングとは、最終的には「コンピューターに何かの計算をさせること」（ここでいう「計算」とは、足し算や引き算などのごく単純な四則演算がほとんどです）です。

しかし中学数学以降の計算には、ほとんど「変数」が出てきます。
プログラミングも同様に変数を扱うことが非常に多いので、本講義では、最初にまず変数を取り扱います。

変数とは、一時的に値を保存、記憶しておく場所です。

<Info>
変数がないと、例えば「計算結果を2回表示するプログラム」を作る際には、2回計算をしなくてはいけなくなります。以下がそのコード例です。

```js
3 * 5
3 * 5
```

このプログラムでは、<math aria-label="3×5"><mn>3</mn><mo>&times;</mo><mn>5</mn></math>を2回計算しています（この結果を利用して別のことを行う際は、もっと複雑なプログラムになります）。

コンピューターは動作があまりにも高速なため、2回程度では全く問題になりませんが、これが1億回…といったレベルで繰り返されていたら無駄な計算が増えてしまいます。
</Info>

変数には、これからこの変数を使用することを**宣言**した後、**代入**と**参照**という2通りの使い方ができます。
代入は変数に値を入れることです。
参照は変数から値を読み込むことです。読み込んだ後、プログラムで使用したりします。

変数は、自分でその変数の名前を決め、宣言することで使用可能になります。
宣言せずに使用（代入もしくは参照）すると、たいていの場合エラーが発生します。

今回は、`a` という変数を宣言し、使用することにします。
宣言にはいくつか方法があるのですが、今回は `let` キーワードを使用します。
```js
let a;
```

JavaScript において、**宣言時に型の指定は行いません**。
プログラムを動作させる際に、自動的に型が付けられます。

この変数に値を代入するには、以下のように記述します。
それぞれ、右辺に示された値を変数 `a` に代入しています。
```js
a = 1;
a = 0.1;
a = "任意の文字列";
a = 1 + 2 + 3 + 4 + 5;
```

また、宣言と同時に値を代入する（一般的に、初期化と呼ばれる）ことができます。
```js
let a = "宣言しつつ、この文字列を a に代入";
```

### 宣言方法の違いについて
JavaScript には3つの変数の宣言方法があります。
それぞれ `var`, `let`, `const` です。

これらには明確な違いがあります。

#### let
`let` は `var` に置き換わる新しい記法です。

`let` は、`var` と比較して変数を利用できるスコープが限られていることが特徴です。
**スコープについては少々難しい概念のため、本講義で取り扱う対象としていません**。

<Tips>
**【上級者向け: スコープについて】**

スコープとは、変数が利用できる範囲です。
`let` や `const` を使用して宣言された変数は、スコープの範囲が限定されています。

例えば、以下のようなプログラムがあるとします。

```js
if (true) {
    var a = 1;
}
if (true) {
    let b = 2;
}

a // 1
b // ReferenceError: b is not defined
```

if 文の外で参照するときに、`var` で宣言された `a` は参照・代入が可能ですが、`let` で宣言された `b` は参照・代入が不可能です。
</Tips>

#### const
`const` は `var`, `let` と異なり、**初期化した後に代入することができない変数**、**定数**を宣言します。スコープの範囲は `let` と同様です。
初期化後に代入しようとすると、エラーが発生します。

```js
const TAX_RATE = 0.1;

TAX_RATE = 0.2; // 実行時、ランタイムでエラー発生！
```

プログラム全体で普遍的な定数値（税率や円周率など）は、大文字とアンダーバーで命名する慣習があります。

### 用途

変数を使用することで、例えば商品の値段から税率を計算するプログラムのメンテナンスを手軽に行うことができます。

ある商品の値段から、その消費税（ここでは10%とする）を計算し、変数 `tax_included_price` に代入するプログラムは以下の通りです。

```js
const TAX_RATE = 0.1;
let price = 100;

tax_included_price = price * TAX_RATE;
```

このように変数を利用することで、プログラムの作成を効果的に進めることができます。

## 算術演算子
計算を行わせるための**演算子**には三種類あり、**算術演算子**・**比較演算子**・**論理演算子**が挙げられます。

<math aria-label="1+1"><mn>1</mn><mo>+</mo><mn>1</mn></math> など、コンピューターに数値を計算させるためには、算術演算子を使用します。
以下のように記述します。

```js
1 + 1
```

出力はしていませんが、内部的に計算は実行されています。

<InlineImages>
    <CaptionImage src="/attachments/meister/js/2025/1/calculation-html.webp" caption="1 + 1 を計算し、HTML を用いて画面に出力する例。" />
    <CaptionImage src="/attachments/meister/js/2025/1/calculation-nodejs.webp" caption="Node.js で 1 + 1 の結果を出力している例。" />
</InlineImages>

演算子を用いた部分は式として扱われ、通常の値と同じように使用できます。
つまり、その結果を変数に代入したり、後述する関数の引数として利用できます。
これは、後述する比較演算子や論理演算子についても同様です。


```js
let a = 2;
let b = a + 5;

some_function(b - 3);
```

### 演算子一覧

代表的なものでは、以下の演算子が使用できます。

| 演算子 | 意味 |
| - | - |
| `+` | 加算（足し算） |
| `-` | 減算（引き算） |
| `*` | 乗算（掛け算） |
| `/` | 除算（割り算） |
| `%` | 剰余（割り算の余り） |
| `**` | べき乗 |

### 計算の優先順位
数学において、計算順序が低い演算を優先させたいときは `()` を使用します。
例えば、<math aria-label="(3+5)×2"><mo>(</mo><mn>3</mn><mo>+</mo><mn>5</mn><mo>)</mo><mo>&times;</mo><mn>2</mn></math> などが挙げられます。

JavaScript においても、計算の順序は数学と同様です。
掛け算が先に行われ、足し算が最後に行われます。

もし足し算を先に行わせたい場合、JavaScript でも `(3 + 5) * 2` と記述できます。
ただし、`()` は全角ではなく半角を使用しなければならないことに注意してください。

### インクリメント・デクリメント

変数を 1 加算することを「インクリメント」、 1 減算することを「デクリメント」と呼びます。こちらは、結果を何か別のものに利用するというより、単純に 1 加算したいだけのときに使用されることが多いです。

使用する場所は多いとは言えませんが、第2回で説明するfor文などで主に使用されます。

例えば、変数 `a` をインクリメントするには以下のように記述します。

```js
a++;
```

また、デクリメントを行うには以下のように記述します。

```js
a--;
```

インクリメント・デクリメントは式なので、上記の例は式文です。
式として扱った場合、その評価はインクリメント・デクリメントを行う前の `a` の値です。

<Tips>
**前置インクリメント**というインクリメント・デクリメントも使用できます。

```js
++a; // 前置インクリメント
--a; // 前置デクリメント
```

この場合は、評価結果はインクリメント後の `a` の値になります。
</Tips>

### 文字列の連結
文字列型のみ、特別に `+` 演算子で文字列を結合することができます。

```js
"Hello " + "World" + "!" // "Hello world!" と等価
```

これは、変数に格納された値を表示する際などにとてもよく使用されます。

```js
let today_weather = "晴れ";

"今日の天気は" + today_weather + "です" // "今日の天気は晴れです"
```

## 比較演算子
比較演算子とは、その名の通り値を比較し、その結果をブーリアン値で返す演算子です。

| 演算子 | 機能 | 例 |
| --- | --- | --- |
| `==` | 等価であるかを比較する | `"abc"` と `"def"` は同じであるか: `"abc" == "def"`（結果は偽） |
| `!=` | 等価でないかを比較する | `"abc"` と `"def"` は異なるか: `"abc" != "def"`（結果は真） |
| `<` | 左辺が右辺未満であることを比較する | `5` は `2` 未満か: `5 < 2`（結果は偽） |
| `<=` | 左辺が右辺以下であることを比較する | 変数 `hensuu` は `3` 以下か: `hensuu <= 3`（結果は `hensuu` に代入された値によって異なる） |
| `>` | 左辺が右辺より大きいことを比較する | `1` と `-5` は左辺が大きいか: `1 > -5`（結果は真） |
| `>=` | 左辺が右辺以上であることを比較する | `"abc"` は `-5` 以上か: `"abc" >= -5`（`"abc"` は数値に比較できないため、結果は常に偽） |
| `===` | **厳密に**等価であるかを比較する | `"3"` と `3` は厳密に同じであるか: `"3" === 3`（文字列と数値で比較しており、型が異なるため偽） |
| `!==` | **厳密に**等価でないかを比較する | `3` と `3` は厳密に異なるか: `3 !== 3`（結果は偽） |

比較演算子も、算術演算子とほぼ変わりがありません。
結果として数値や文字列ではなく、ブーリアン値が返ってくるのみです。

そのため、比較演算子の結果を変数に入れて、後で使用することもできます。

```js
const isGreater = 10 > 5; // 定数 isGreater には true が入っている
```

## 論理演算子
論理演算子とは、ブーリアン値を演算し、新しいブーリアン値を作るものです。

| 演算子 | 機能 | 演算子の場所 | 例 |
| --- | --- | --- | --- |
| `!` | ブーリアン値を反転する | 値の前 | 式 `3 < 5` の評価結果を反転する: `!(3 < 5)`（結果は偽） |
| `&&` | 両方のブーリアン値が真の場合にのみ真を返す（論理積） | 値と値の間 | `true && false` の評価結果は `false` |
| `\|\|` | 少なくとも片方のブーリアン値が真であれば真を返す（論理和） | 値と値の間 | `true \|\| false` の評価結果は `true` |

例えば、以下のようにブーリアン値を演算します。

```js
3 < hensuu && hensuu < 10 // hensuu は3より大きく、かつ10より小さい
```

これらの演算子を組み合わせることで、複雑な論理式を構築し、条件分岐やフラグ管理に活用することができます。

## テンプレートリテラル
先ほど、文字列を結合する際は `+` 演算子を使用することができると述べました。

しかし、例えば以下のような例においては、それが不便になってしまうこともあります。

```js
let year = 2025;
let month = 1;
let day = 10;
let hours = 12;
let minutes = 37;
let seconds = 34;
let name = "Alice";

let message1 = "現在時刻は" + year + "年" + month + "月" + day + "日" +
    hours + "時" + minutes + "分" + seconds + "秒です！";
let message2 = "Hello, " + name + "!";
```

このように、特に日時などをフォーマットする際、非常に長く、読みづらいコードになってしまうという問題点があります。

これを解決するのが、文字列表現の延長線上にある**テンプレートリテラル**です。
テンプレートリテラルは文字列の中に**式を評価した値を埋め込める**機能です。

テンプレートリテラルを使用するには、`"` （ダブルクォーテーション）ではなく、<code>\`</code> で文字列を囲みます。
その中で `${` `}` を使用することで、式を埋め込むことができます。

<Caution>
<code>\`</code> はシングルクォーテーション `'` とは異なります。
Shift を押しながら `@` キーを押すと入力できます。
</Caution>

```js
// 各種変数は上と同様

let message1 = `現在時刻は${year}年${month}月${day}日${hours}時${minutes}分${seconds}秒です！`;
let message2 = `Hello, ${name}!`;
```

先ほど示したコードは、このように書き直すことができます。

<Hint>
テンプレートリテラルの大まかな理解としては、C における printf の引数に近いです。
</Hint>

## 型安全なプログラムを書く
JavaScript でプログラミングする際には、**型の整合性**を意識することが重要です。

これを怠ると、意図しない型の値が扱われることで予期せぬエラーに繋がることがあります。

### 異なる型同士の演算
例えば、異なる型同士を演算してみるとどうなるでしょうか。

#### 数値 + 文字列
例えば、`1 + "1"` (数値 + 文字列) は、`"11"` (文字列) です。
```js
1 + "1" // "11"
```
数値が文字列に**暗黙的に変換され**、文字列が連結されたような挙動を示します。

#### 数値 - 文字列
では、`1 - "1"` (数値 + 文字列) はどうなるでしょうか。`""` (空文字) ではなく、`0` (数値) です。
```js
1 - "1" // 0
```
今度は、文字列が数字に変換され、`1 - 1` と同じ挙動を示します。

そのため、`10 - "5"` は `5` になります。

#### 数値 * 文字列
`1 * "a"` (数値 * 文字列) を計算すると、`NaN` という、数でないことを示す数になります。

#### 数値 + ブーリアン
ブーリアン値も試してみましょう。
`1 + true` は何になるでしょうか。

...

```js
1 + true // 2
```

答えは `2` です。
`true` が `1` に変換されます。

同様に、`1 + false` は `1` です。
`false` は `0` に変換されます。

### 異なる型同士の比較
先ほどは演算でしたが、比較についても見てみましょう。

これは JavaScript でよく扱われる話題で、分かりやすく図解しているサイト「[JavaScript-Equality-Table](https://dorey.github.io/JavaScript-Equality-Table/)」があります。

<CaptionImage src="/attachments/meister/js/2025/1/javascript-equality-table.webp" caption="「JavaScript-Equality-Table」の画面。" to="https://dorey.github.io/JavaScript-Equality-Table/" />

左辺もしくは右辺を縦軸、もう一方を横軸にして読みます。

このサイトによると、例えば以下の比較はすべて `true` です。

```js
"" == false
0 == false
undefined == null
```

`""` (空文字列) が「偽」と等しい、また 0 は偽と等しい……など、直観に反しているものが多いでしょう。
これは実際とても困る仕様です。

#### 例

例えば、何かの変数が `false` であることを検証しているプログラムがあったとしましょう。

この変数に何かの拍子に `0` が入ってしまったとします。
その場合、`0 == false` が成立し、変数は実際には `false` ではないのに、この比較が真（`true`）になってしまいます。
これは、プログラムの誤動作を引き起こす可能性があり、非常に危険です。

<Tips>
**【上級者向け: 「何かの拍子」とは】**

> この変数に何かの拍子に `0` が入ってしまったとします。

実際、このミスは起こりえなさそうで起こりえます。

```js
function checkCondition(value) {
    if (value.precondition == false) return 0;

    // とてもとても長い処理

    if (...) {
        if (...) {
            // 何かの処理
        } else if (...) {
            // 何かの処理
        } else {
            // 長い処理の中だから書き換えを忘れちゃった
            return false;
        }
    }

    // とてもとても長い処理

    return 1;
}
```

この場合、関数の戻り値として `0` か `1` が考えられます。

「最初はブーリアン値を返していたが、仕様変更で数値を返すようになった。ただ、書き換えを忘れてしまった」などはよくある話です。
</Tips>

### 動的型付け
……もちろん、JavaScript を扱うプログラマーが上記すべての挙動を暗記しているわけではありません。
意図してこの演算を行った場合でも、自分のミスや、他者にとって意図がつかめないコードになってしまう場合が多いです。

そのため、異なる型同士での演算は、**基本的に行うべきではありません**。

実は、JavaScript は**動的型付け言語**と呼ばれる言語の一種で、型を実行時に判定します。
そのため、このような異なる型同士での演算を事前に検出することはできません。

<Tips>
異なる型同士での演算は基本的に行うべきではないですが、例外として「数字 + 文字列」は使用することがあります（個人の感想）。

数字を文字列に変換する方法として、`.toString()` メソッドを使う方法（詳しくは第4回で解説します）があるのですが、これを毎回書いていると冗長になるためです。

```js
let my_height = 150;

"私の身長は" + my_height + "cmです" // 文字列 + 数字 + 文字列。数字は文字列に変換され、その後文字列同士での結合が行われる
```
</Tips>

<Tips>
「さすがに不便だ」ということで、JavaScript の構文を拡張し、型を付けるプログラミング言語である **TypeScript** が存在します。

TypeScript を実行する際には JavaScript に**トランスパイル**（変換）し、実行します。
これにより、JavaScript の膨大なライブラリなどの資産を TypeScript でも使用することができます。

現代の大規模な JavaScript プログラムの開発は、主に TypeScript を使用していることが多いです。
</Tips>

### 厳密な比較を行う
ではどのように対策すべきかというと、第3回・第4回で解説する `parseInt` 標準関数や、`toString` メソッドなどで明示的に型変換を行うこと、および等価の比較にはなるべく `===` を使用することが挙げられます。

先ほどの[比較演算子](#比較演算子)の項で、`===` は**厳密に等価か**を比較すると説明しました。

`===` は、暗黙的な型変換を行わず、値と型の両方が一致している場合にのみ `true` を返します。

```js
"" === false // false（異なる型）
0 === false  // false（異なる型）
undefined === null // false（異なる型）
```
