## インデント
プログラミングにおいては、一般的にコードの可読性を高めるために**インデント**を付けます。

インデントとは、スペースもしくはタブによって左側に空白をつけ、ブロック (`{}`) がどこからどこまで続いているかを視覚的にわかりやすくするものです。

```js
if (条件) {
    // この行はインデントされています
    文;

    if (条件) {
        // さらにもう一段階インデントをつけます
    }
}
```

この講義においても、以降はインデントを使用します。

## 条件分岐
どんな複雑なプログラムも、原理的には条件分岐と繰り返し、第1回で説明した[数値の計算（四則演算やインクリメントなど）](./1#算術演算子)のみによって構成されています。

今回は if 文という、プログラムで条件分岐を行う構文について学習します。

### 構文
JavaScript で if 文を使用するには、「分岐するかしないか」の判定に[ブーリアン値](./1#ブーリアン型)を指定し、以下のように記述します。

```js
if (ブーリアン値に評価される式) {
    文;
    文;
    ...;

    // if の中に if を置くことも有効
    if (...) ...;
}
```

もしくは、プログラムが1行で完結する文であれば、以下のように記述することもできます。

```js
if (ブーリアン値に評価される式) 文;
```

### 条件指定
if 文の条件におけるブーリアン値とは、`true` や `false` の固定値を指定するという意味ではなく、大抵は[比較演算子](./1#比較演算子)の結果を使用します。

例えば、「[変数](./1#変数) `a` の値が 5 より大きければ」という条件であれば、以下のように記述できます。

```js
if (a > 5) {
    ...
}
// もしくは
if (5 < a) {
    ...
}
```

#### 条件を変数に代入する
if 文の条件はブーリアン値であればよいので、例えば以下のようなこともできます。

```js
let is_high_temperature = temperature > 25;
if (is_high_temperature) ...
```

これは、同じ条件を複数の if 文で使用したり、条件に明確な名前を指定しておきたい場合に便利です。

### else if 句と else 句
if 文には、[論理演算子 `!`](./1#論理演算子) ではなく、文自体の機能として「○○以外だった場合」という条件も指定できます。それが、else if 句と else 句です。

else if は「そうでなければ、もし」、 else は「そうでなければ」という意味です。
例えば、以下のように使用します。

else if 句には、先ほどと同じように条件を記述することができます。

```js
if (a <= 5) {
    // a が 5 以下
} else if (a <= 10) {
    // a が 10 以下
    // ただし、アルゴリズム的に 5 より大きくないと実行されない
} else if (a <= 15) {
    // a が 15 以下
    // ただし、アルゴリズム的に 10 より大きくないと実行されない
} else {
    // すべての条件に当てはまらないとき（a が 15 より大きい）
}
```

else if 句は、それ以前に記述された条件に当てはまらないかつ、指定された条件にも当てはまらない場合実行されます。

else 句は、それ以前に記述された条件に当てはまらない場合実行されます。

<Caution>
**それ以前に記述された条件に当てはまらない**ということに注意してください。

```js
if (a <= 5) {
    ...
} else if (a <= 10) {
    ...
}
```

例えば、このようなコードであれば、記述されている条件は確かに「`a` が 5 以下の場合」と「`a` が 10 以下の場合」です。

しかし、if 文は最初に適合した条件のブロックに入ります。
そのため、`a` が 5 以下の場合であれば、必然的に二つ目のブロックには入らないのです。
</Caution>

<Caution>
else if 句や else 句は if 文のブロックのすぐ後に記述する必要があります。

例として、以下のプログラムは正常に動作しません。

```js
if (a <= 5) {
    a = a + 10;
}
a = a + 10;

else {
    a = 0;
}
```
</Caution>

### 三項演算子
例えば、ある条件に対して 0 か 1 を代入したい変数があったとします。

```js
const condition = true;

let number = (condition に合わせて 0 か 1 を代入したい！);

// if 文で実装するなら:
if (condition) {
    number = 1;
} else {
    number = 0;
}
```

ただし、このように単純な条件で式を表現するような場合、if 文より**三項演算子**を使用するとより簡潔に記述することができます。

三項演算子は `条件 ? 真の場合の値 : 偽の場合の値` という形式で使用します。

```js
let message = temperature > 25 ? "暑いです" : "暑くありません";
```

これは以下の if 文と同じ意味になります。

```js
let message = "";
if (temperature > 25) {
    message = "暑いです";
} else {
    message = "暑くありません";
}
```

## 配列
**配列**は、複数の値を連結したリストのように扱える概念です。

これは、数学の数列に近いものがあります。
そのため配列は、後述する繰り返しと併せて用いられることが多いです。

配列は、以下のような式で定義します。

```js
[1, 2, 3, 4, 5]
```

空の配列は、以下のような式で定義します。

```js
[]
```

<Tips>
配列の要素を区切るカンマ (`,`) の後のスペースは任意です。
</Tips>

配列の中身は、数値である必要はありません。
文字列やブーリアン値、配列そのものを入れることもできます。

```js
["Red", "Blue", "Yellow", "Green", "Purple"]
[[1, 2, 3], [4, 5, 6]]
```

<Tips>
配列に複数の型を持つ値を入れることもできます。

ただし、あまりユースケースはありません。
第1回で説明したように、型を混在させた場合にはプログラムする上でミスが起こりやすくなってしまうからです。

```js
[1, "Keio-line", 2, [3, 4], true, "Chuo-line"]
```
</Tips>

### 参照・代入
配列の各要素を参照、あるいは各要素に代入するには、配列に対して `[0]` という形式で順番を指定することで実現できます。

この順番のことを**インデックス**と呼びます。
インデックスは、`0` から始まります。

```js
// 配列から 0 番目を参照する例
[1, 2, 3, 4, 5, 6][0]

// 変数に代入した配列から 1 番目を参照する例
let array = ["Alpha", "Beta", "Gamma"];
array[1]
```

代入は、インデックスを指定しつつ、変数と同じように記述します。

```js
array[0] = "α";
array[1] = "β";
array[2] = "γ";
```

#### 変数によるインデックス指定
インデックスは、`0` という数値、つまり式が指定されています。

つまり、式として変数を指定することもできます。

```js
const index = 2;
array[index] // array[2] と同じ
```

### 配列の長さを取得する
配列は後ろに `.length` とつけることによって、配列の長さを値に持つ変数を使用することができます。

`.` の意味などについては、第4回で解説します。

```js
let array = [1, 2, 3, 4, 5];

array.length // 5 という値を持つような変数として扱える

// こんな風に
if (array.length > 5) ...;
```

これを使用して、次に示すような繰り返し処理では、配列の中身に対して繰り返し何かしらの処理を行うことがあります。

## 繰り返し
次に、プログラムに同じ動作を何回も行わせる、**繰り返し**を学習します。

繰り返しを実装するには、JavaScript では **for 文**、および **while 文**を使用します。
英語では for という単語には〝繰り返し〟という意味はあまり感じにくいですが、プログラミングにおいては繰り返しの意味で使用されることが多いです。

### for 文
for 文は、一番よく使われる繰り返しの構文で、以下のように記述します。

```js
for (最初に行われる操作; 繰り返しを続ける条件; 1回実行後に行われる操作) {
    文;
    文;
    ...
}
```

もしくは、繰り返すプログラムが1行で完結する文であれば、以下のように記述することもできます。

```js
for (最初に行われる操作; 実行する条件; 1回実行後に行われる操作) 文;
```

for 文の中にあるのは、それぞれ最初に行われる文、実行するかどうかを判定する式、1回実行後に行われる文です。

そのため、例えば繰り返しを続ける条件が比較演算子でなくても、1回実行後に行われる操作がなくても実行できます。

```js
// 普通こんな書き方はしませんが、繰り返しを続ける条件を for 文の中に書いても問題ありません
for (let i = 0; true; i++) {
    if (i > 3) break;
    console.log(i);
}

// 普通こんな書き方はしませんが、一回実行後に行われる操作を for 文の中に書いても問題ありません
for (let i = 0; true;) {
    if (i > 3) break;
    console.log(i);
    i++;
}
```

#### よく使用される for 文
for 文の内容は、何かを繰り返したいとき、大抵以下のように記述されます。

```js
for (let i = 0; i < 繰り返し回数; i++) ...
```

先ほど構文として紹介した `最初に行われる操作; 実行する条件; 1回実行後に行われる操作` について、これを例に説明すると、以下のようになります。

##### 最初に行われる操作
最初に、ループ内で使用する変数を定義します。

よく使用されるのは、何回ループしたかを 0 始まりで示す `i` という名前の変数です。

<Tips>
ここにおける変数 i は、繰り返し内の処理で使用できます。
</Tips>

##### 実行する条件
次に、for 文の繰り返し内容として指定されている処理の実行可否について判断します。

例えば、`i < 5` と指定すると、`i` が 5 未満の場合に次の処理が行われます。

##### 1回実行後に行われる操作
最後に、繰り返し内容が1回実行されると行われる操作を定義します。

例にある `i++` は、変数 `i` をインクリメントしています。

これらの操作によって、指定した回数ループをしつつ、繰り返し内で「今何回目？」を取得できるようにしているのです。

### while 文
while 文は、もっとも簡単な繰り返しの構文で、以下のように記述します。

```js
while (繰り返しを続ける条件) {
    文;
    文;
    ...
}
```

もしくは、繰り返すプログラムが1行で完結する文であれば、以下のように記述することもできます。

```js
while (繰り返しを続ける条件) 文;
```

「繰り返しを続ける条件」は、ブーリアン値で指定します。
そのため、ブーリアン値を出力する式として、比較演算子を使用することもできます。

```js
while (i < 3) { // i が 3 未満なら
    ...
}
```

#### 例
「3回繰り返す」というプログラムであれば、以下のように記述できます。

```js
let i = 1;
while (i <= 3) { // i が 3 以下なら
    // ここは、i = 1 のとき、i = 2 のとき、i = 3 のときに実行される

    i++; // i を 1 増やす（インクリメント）
}
```

### for...of 文
配列の各要素に対して繰り返し処理を行いたい場合、**for...of 文**を使用すると便利です。

今まで、配列の各要素に対してアクセスする際は、以下のように書いていました。
for...of 文では、それを短縮できます。

```js
// 従来の方法
for (let i = 0; i < array.length; i++) {
    array[i]
}

// for...of 文を使用した場合
for (const 要素を格納する変数名 of 配列) {
    指定した変数名
}
```

<Tips>
例示したコードでは、変数の宣言は `const` で行っています。

以下の for...of 文は、以下の for 文に書き換えられます。

```js
for (const element of array) {
    element
}

for (let i = 0; i < array.length; i++) {
    const element = array[i];
}
```

この場合、たとえ `let` で変数を宣言したとしても、配列本体を変更することはできません。

そのため、`const` で変数を宣言することが一般的です。
</Tips>

例として、配列の各要素を順に表示する場合を考えます。

```js
const fruits = ["apple", "banana", "cherry"];
for (const fruit of fruits) {
    fruit // "apple", "banana", "cherry"
}
```

for...of 文は、各要素の値に直接アクセスできます。
そのため、配列のインデックスを意識する必要がなく、インデックスを必要としない場合、コードをよりシンプルに記述できます。

<Tips>
for...of 文は、配列だけでなく文字列に対しても使用できます。

その場合、1文字ずつ分割された配列のような挙動を示します。

```js
const message = "Hello world!";
for (const char of message) {
    // この中身は各文字に対して実行される
}
```

**上級者向け:** この講義では解説しませんが、これは文字列が Iterable なオブジェクトであるためです。
</Tips>

### break 文
次は、繰り返しの制御について学習します。

for や while などのループを途中で抜け出したいときには、`break;` という文が使用できます。

例えば、数値が格納された配列の合計を計算するプログラムにおいて、配列の中に `-1` が見つかった時点で計算を終了するプログラムなどを実装できます。

```js
// 配列の中身を読み込み、合計を計算する
const array = [3,2,1,4,7,9,5,3,6,9,-1,2,3,9,7,9,5,0,6,1,0,6,4,9,3,5,9,9];
let sum = 0;
for (let i = 0; i < array.length; i++) {
    // もし -1 があれば、その時点でループを終了
    if (array[i] === -1) break;

    sum = sum + array[i];
}
```

### continue 文
また、ループの内容をすぐに終了させ、次のループ継続判断に処理を移動したい場合、`continue;` という文が使用できます。

continue 文を使用するのは、何か繰り返し内でデータを処理するにあたり、無視するべきデータが出てきた場面などです。

```js
// 配列の中身を確認し、0 ならスキップ、1 ならインクリメント、2 ならデクリメント
const array = [0, 0, 1, 0, 1, 2, 0, 2, 2, 1, 2];
let counter = 0;
for (let i = 0; i < array.length; i++) {
    if (array[i] === 0) {
        continue;
    } else if (array[i] === 1) {
        counter++;
    } else if (array[i] === 2) {
        counter--;
    }
}
```
