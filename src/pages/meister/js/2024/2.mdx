## コメント

本題に入る前に、コメントについての前提知識をつけておきましょう。

コメントは、プログラムで無視される行・あるいは範囲のことです。
それだけです。

### 構文

1行をコメントにするには、以下のように記述します。
Webページでは、文字が灰色になっている部分がコメントです。

```js
何かの処理... // ここからがコメント
```

また、複数行や任意の範囲をコメントにすることができます。

```js
.../* ここから
ここも
さらにここも
ここまでコメント */...

.../* ここがコメント */...
```

直接プログラムの開発に関係するものではありません。
しかし、プログラム中でメモをしておくことは重要です。

プログラムが複雑になればなるほど、一目で行っている処理を把握することは難しくなります。
また、今後実装する予定のものをプログラムに書いておいたりすると、雑な高専生でもタスク管理が少しだけできるようになります。コードを見ればいいからです。

### アノテーションコメント

コメントにはアノテーションコメントという概念があります。

コメントを形式化し、意味を持たせるためにできた概念です。

| 意味 | 例 |
| --- | --- |
| あとでやる（ToDo） | `// TODO: この処理を最適化する` |
| 複雑なコードに簡易的な解説をつける | `// NOTE: このif文では受信したパケットの総数が0であることを確認する` |

[@taka-kawa さんによる 「TODO: 以外のアノテーションコメントをまとめた」という記事](https://qiita.com/taka-kawa/items/673716d77795c937d422#よく使われる記法と意味) が役に立つかもしれません。

## 型の概念
第一回でJavaScriptには型がないと少し説明しましたが、内部的にはもちろん「数値」と「文字列」などが区別されて扱われるわけで、多少その概念は理解しておく必要があります。

### 型の種類
JavaScriptには以下のような型があります。
- 数値(Number)型
    ```js
    1
    2
    3
    100
    -345.678
    Infinity
    ```
- 文字列(String)型
    ```js
    "Hello World!"
    ""
    ```
- 真偽値(Boolean)型
    ```js
    true
    false
    ```
- undefined型
    ```js
    undefined
    void 0
    ```
- null型
    ```js
    null
    ```
- Symbol型
- BigInt型
- オブジェクト型

この回では、数値型、文字列型、真偽値型を中心に説明します。

#### 真偽値型とは
数値、文字列は聞き馴染みがありますが、真偽値型は聞き馴染みがないという人も居ると思います。
真偽値型は、「はい」「いいえ」をあらわす型です。JavaScriptでは「はい」は`true`、「いいえ」は`false`で表します。
後述するif文などで使われます。

### 異なる型どうしを足し算するとどうなる？
```js
document.write("1" + 1);
```
このようなコードを実行するとどうなるでしょうか？  
`"1"`は当然文字列、`1`は数値です。
実際に実行してみると、画面には`11`と表示されます。JavaScriptでは、文字列と数値を足し算すると数値が文字列に変換されてから足し算されます。
しかし、こうではなく「2」としてほしい場合があるでしょう。
その場合は、明示的に型変換を行う必要があります。
型変換は以下のような方法で行うことができます。
```js
document.write(Number("1") + 1);
// 整数として受け取りたい場合
document.write(Number.parseInt("1") + 1);
// 小数として受け取りたい場合
document.write(Number.parseFloat("1") + 1);
```
<Info>
`Number()`なら整数も小数もうまく変換できるのに、なぜ`parseInt()`や`parseFloat()`があるのか？と思った人がいるかもしれません。  
`Number()`は、文字列が数値に変換できない場合、`NaN`(Not a Number、の意)を返します。`parseInt()`や`parseFloat()`は、数値に変換できない場合、`NaN`を返す代わりに、変換できる部分だけを返します。
また、`Number`は`"1e3"`(コンピューターにおいて一般に<math aria-label="1×10^3"><mn>1</mn><mo>×</mo><msup><mn>10</mn><mn>3</mn></msup></math>という意味)を`1000`として解釈しますが、`parseInt`は純粋な数値のみを扱うので`1`として解釈します。
</Info>

また、`11`と返すのを期待している場合も、明示的に型変換を行うことでより安全にコードを書くことができます。
```js
document.write("1" + String(1));
// あるいは
document.write("1" + (1).toString());
```
表示される値は全く同じ`11`ですが、単純に`"1" + 1`と書いてしまうと予想しにくかったコードも、このように書くことで予想しやすくなり、バグの発見に役立ちます。不要な場合はJavaScriptのひどい挙動を利用せず、前提知識不要なコードを書くことを心がけることが大切です。

このような型変換は、足し算だけでなく、比較演算子などでも同様に行われます。
```js
document.write("1" === 1); // false
```
`===`演算子は、厳密に等しいかどうかを判定する演算子です。この場合、`"1"`と`1`は異なる型なので、`false`が返されます。
しかし、"1"を数値に変換してから比較する(または数値を文字列に変換してから比較する)ことで、`true`を返すことができます。
```js
document.write(Number("1") === 1); // true
// または
document.write("1" === String(1)); // true
```

<Info>
「JavaScript のひどい挙動」というのは具体的に以下のようなものです。

```js
null == undefined // これは true である
-1 == false // これは false である
0 == false // これは true である
1 == true // これは true である
2 == true // これは false である

// なお、これらの式は厳密に比較（===）するとすべて false である
```

……ということが言いたかったんだと思います。
確かにまあ……ひどいとは思いますね。
</Info>

## 条件分岐

どんな複雑なプログラムも、原理的には条件分岐と繰り返し、あとちょっとした数値の計算（インクリメントから割り算、ビット演算など膨大な量の手段はありますが）のみによって構成されています。

今回は if 文という、プログラムで条件分岐を行う構文について学習します。

### 基本構文

JavaScript で if 文を使用するには、以下のように記述します。

```js
if (条件) {
    プログラム
}
```

もしくは、プログラムが1行で完結する内容であれば、以下のように記述することもできます。

```js
if (条件) プログラム
```

### 比較演算子

if 文の条件には、以下の演算子を使用して変数等の比較を行うことができます。

| 演算子 | 機能 | 例 |
| --- | --- | --- |
| `==` | 等価であるかを比較する | `"abc"` と `"def"` は同じであるか: `"abc" == "def"`（結果は偽） |
| `!=` | 等価でないかを比較する | `"abc"` と `"def"` は異なるか: `"abc" != "def"`（結果は真） |
| `<` | 左辺が右辺未満であることを比較する | `5` は `2` 未満か: `5 < 2`（結果は偽） |
| `<=` | 左辺が右辺以下であることを比較する | 変数 `hensuu` は `3` 以下か: `hensuu <= 3`（結果は `hensuu` に代入された値によって異なる） |
| `>` | 左辺が右辺より大きいことを比較する | `1` と `-5` は左辺が大きいか: `1 > -5`（結果は真） |
| `>=` | 左辺が右辺以上であることを比較する | `"abc"` は `-5` 以上か: `"abc" >= -5`（比較不能なため、結果は偽） |
| `===` | 厳密に、等価であるかを比較する | `"3"` と `3` は厳密に同じであるか: `"3" === 3`（文字列と数値で比較しており、型が異なるため偽） |
| `!==` | 厳密に、等価でないかを比較する | `3` と `3` は厳密に異なるか: `3 !== 3`（結果は偽） |

以下に例を示します。

```js
if (hensuu >= 5) {
    document.write("hensuu は 5 以上です");
}
```

#### 比較演算子の結果を変数に代入する

また、`hensuu >= 5` のような比較演算子を利用した比較式自体が、一つの命令となっています。

よって、以下のプログラムも有効です。

```js
// NOTE: hensuu が 1000000 より大きいかどうか（true or false）を、 is_big_number 変数に代入する
var is_big_number = hensuu > 1000000;
```

この変数の型は boolean です。つまり、この比較演算子の結果によって `true` もしくは `false` が代入されます。

### boolean 型変数を条件として利用する

先ほど boolean 型の変数を作成しましたが、これを if 文でそのまま使用することができます。

```js
if (is_big_number) {
    // 何かの処理
}
```

### 論理否定演算子

`!` を使用して、`true` を `false` に、 `false` を `true` に反転させることが可能です。

例えば、以下のような用途に使用できます。

```js
if (!is_big_number) {
    // 何かの処理
}
```

単純に反転しているだけなので、`!true` は `false` です。

#### 代替案: false を利用する

冗長ですが、論理否定演算子は `false` を利用して以下のように書き換えることも可能です。

```js
if (hensuu >= 5 === false) {
    document.write("hensuu は 5 以上ではありません");
}
```

これは、「『hensuu が 5 以上であること』が偽であること」という条件になります。

やや複雑になりますが、このように比較演算子の結果を比較演算子で比較することもできます。

変数に代入したコードに置き換えてみるとわかりやすくなるかもしれません。

```js
if (is_big_number === false) {
    // 何かの処理
}
```

### 論理演算子

また、先ほどの比較演算子を連結することもできます。

例えば、「AかつB」といったように、どちらも当てはまる条件の時に処理を行わせたいときがあります。また、「AまたはB」など、どちらかが当てはまったら処理を行わせたい、といったこともあります。

| 演算子 | 機能 | 例 |
| --- | --- | --- |
| `&&` | かつ | hensuu は 3 より大きく、5未満であるか: `3 < hensuu && hensuu < 5` |
| <code>&#124;&#124;</code> | または | hensuu は 10 または 20 であるか: <code>hensuu == 10 &#124;&#124; hensuu == 20</code> |

<Tips>
この話は、1年生の基礎数学の「集合と論理」の単元と似ています。

ここまでで何の話か心当たりがない場合は、先読み・復習をしておくとよいかもしれません。
</Tips>

### else-if 句と else 句

else-if は「そうでなければ、もし」、 else は「そうでなければ」です。

例えば、以下のように使用します。

```js
if (hensuu <= 5) {
    // hensuu が 5 以下
} else if (hensuu <= 10) {
    // hensuu が 10 以下
    // ただし、アルゴリズム的に 5 より大きくないと実行されない
} else if (hensuu <= 15) {
    // hensuu が 15 以下
    // ただし、アルゴリズム的に 10 より大きくないと実行されない
} else {
    // すべての条件に当てはまらないとき（hensuu が 15 より大きい）
}
```

else-if 句は、それ以前に記述された条件に当てはまらないかつ、指定された条件にも当てはまらない場合実行されます。

else 句は、それ以前に記述された条件に当てはまらない場合実行されます。

<Caution>
else if 句や else 句は if 文のブロックのすぐ後に記述する必要があります。

例として、以下のプログラムは正常に動作しません。

```js
if (hensuu <= 5) {
    hensuu = hensuu + 10;
}
hensuu = hensuu + 10;

else {
    hensuu = 0;
}
```
</Caution>

<Tips>
厳密には、JavaScriptに`else if`という構文はありません。
`else if`は、`else`と`if`を組み合わせたもので、`else`のあとの`{}`を省略して`if 〜`をつなげているだけです。
</Tips>

## 繰り返し

次に繰り返しを学習します。
繰り返しを実装するには for 文を使用します。
英語では for という単語に繰り返しの意味は（たぶん）ありませんが、プログラミングにおいては繰り返しの意味で使用されることが圧倒的に多いです。

### 基本構文

```js
for (var i = 0; i < 繰り返し回数; i++) {
    // 何かの処理
}
```

もしくは、プログラムが1行で完結する内容であれば、以下のように記述することもできます。

```js
for (var i = 0; i < 繰り返し回数; i++) // 何かの処理
```

for 文の構文は複雑ですが、分割してみると少しわかりやすくなります。

for 文の `()` 内は3つの要素でできており、`;`（セミコロン）で区切ってそれぞれを考えることができます。

* ループ内で使用する変数を定義する。
    * `var i = 0;` で、 i という変数を定義し、0を代入している。
    ::tips
    ここにおける変数 i は、ループ内の処理で使用できます。
    つまり、現在のループ回数を参照したいとき、変数 i を参照すればよい、ということです。
    ::
* ループを続ける条件を指定する。
    * `i < 繰り返し回数` では、変数と繰り返し回数（ここには数値を入れることが多いです）を比較している。
* `()` 内には記述されていないが、ここで `{}` 内の処理が行われる
* ループの最後に、ループを続けるための処理を行う。
    * `i++` で、i をインクリメントしている。

### 例

例として、以下のようなプログラムはどのように実行されるでしょうか。

```js
for (var i = 1; i <= 3; i++) {
    document.write(i);
}
```

答えは `123` です。
`\n` が含まれていないので、改行は行われません。

この手順を説明すると、以下の通りです。

* ループ開始
    * i を定義し、1を代入する。
* 1回目
    * i = 1 である。
    * i &lt;= 3 なので、 i を出力する。
    * i をインクリメントする。
* 2回目
    * i = 2 である。
    * i &lt;= 3 なので、 i を出力する。
    * i をインクリメントする。
* 3回目
    * i = 3 である。
    * i &lt;= 3 なので、 i を出力する。
    * i をインクリメントする。
* ループ終了
    * i = 4 である。
    * i &lt;= 3 ではない。そのため、ループを続行しない。

## 関数を使って処理を行う
関数(function)とは、とてもざっくり説明すると処理をまとめるためのものです。
関数を使うことで、同じ処理を何度も書かなくても済むため、コードの見通しがよくなります。
また、一連の処理に名前をつけることで、その処理が何をしているのかがわかりやすくなります。

### アロー関数式
関数は、以下のように表します。
```js
() => {
    // 処理
}
```

関数を以下のように変数に入れて定義することができます。
```js
var sayHello = () => {
    document.write("Hello, World!");
    document.write("<br />");
}

for (var i = 0; i < 5; i++) {
    sayHello();
}
```
このコードでは、`sayHello`という関数を定義し、その関数を5回呼び出しています。
この程度の処理であれば、関数を使わなくても同じことができますが、処理が複雑になるほど関数を使うことでコードの見通しがよくなります。

### `function`キーワードと巻き上げ
関数には他の記法もあります。
```js
function sayHello() {
    // 処理
}
```

以下のように使います。
```js
function sayHello() {
    document.write("Hello, World!");
    document.write("<br />");
}

sayHello();
```
`() => {}`との違いは、「巻き上げ」という動作です。
`function`で定義した関数は、関数を定義する前に呼び出すことができます。

```js
sayHello();

function sayHello() {
    document.write("Hello, World!");
    document.write("<br />");
}
```
メイン処理を上の方に書いて関数定義を下の方にまとめておきたい場合は`function`を使うと便利です。

</Tips>
