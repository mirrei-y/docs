## はじめに
JavaScript コースをご選択いただきありがとうございます。このコースでは、主に Web アプリケーション制作の基礎およびオブジェクト指向プログラミングの基礎を学ぶことを目的としています。

{/* また、さらに高度な Web アプリケーション制作に役立つコラムをいくつか用意していますので、興味がありましたらそちらもぜひご覧ください。 */}

### 対応している環境

この講義は、Windows・macOS・Linuxに対応しています。

後半でバックエンドコースを学習する方は、Node.js のインストールが必要（最近のものであれば、バージョンを問わない）です。

講義は Windows と Visual Studio Code を用いて作成されていますが、 macOS や Linux をご使用の方は適宜読み替えてください。

### JavaScript とは
JavaScript とは、簡単に言うと Web ページに高度な動きをつけることができるスクリプト言語です。

ご覧になっているこの Web ページにも JavaScript が使われています。

主にブラウザ上で動作しますが、ブラウザ以外の場所でも動作させることができることが特徴です。

<Tips>
Java とは全く異なる言語です。C と C++ の関係性のように、 Java の拡張が JavaScript であったり、 Java 内で JavaScript のコードを書けるといったような機能は**まったくありません**。

いや、 Java 製の JavaScript の VM を使ったら書けるじゃないか！という上級者の方は、ぜひ自作 JavaScript VM を Java で制作してみてください。マイスターのネタになりますよ。
</Tips>

### 経験者の方へ

JavaScript の開発経験がすでにある方は、環境構築が済んでいることと思われます。

この講義では、ブラウザと Visual Studio Code を使用して開発を進めますが、 Visual Studio や Vim、 Emacs などのほかのエディタでも構いません。
Visual Studio もしくは Visual Studio Code 以外のエディタ固有のサポートについては致しませんのでご注意ください。
