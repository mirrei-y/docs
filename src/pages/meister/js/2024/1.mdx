## 用語説明

最初から全部読む必要はありません。わからなくなったら用語説明を見る、くらいがいいかと思います。

### エディタ

テキストエディタのこと。
ここではその中でもプログラミングに特化したテキストエディタを指す。

Visual Studio Code をはじめ、 Visual Studio, EmEditor, TeraPad, Atom, vim, emacs など数多くのエディタが存在する。

### Webブラウザ

主に HTML で記述されたWebページを閲覧できるソフトウェア。
Google Chrome, Firefox, Safari, Microsoft Edge, Opera 等。

### コンピューター

高専生で存在すら知らない人はおそらくいないと思われる、今使っているこれ。

ここでは「PC」と同義とするが、この資料においては**スマートフォンやタブレットなどでも代用できる**。

### サーバー

データを他のコンピューターに送信する（例: Webページのデータの送信）コンピューターのこと。

データを受信したり（例: SNSにおける新規投稿）、データを高速に処理するもの（例: AI関連の処理）も多い。

最近では、一般的なコンピューターと違いはなくなっている。

オンラインゲームではその特性上、ゲームをプレイしているとこの単語を見かけることが多い。
サーバーの動きをするアプリケーション自体を「サーバー」と呼ぶこともある。

対義語は「[クライアント](#クライアント)」。

### クライアント

サーバーからデータを受信し、実際に使う人にデータを表示するコンピューターのこと。

オンラインゲームなどでは、アプリケーション自体を「クライアント」と呼ぶこともある。

対義語は「[サーバー](#サーバー)」。

### HTML

Webページの大まかな構造を決定する言語。

タグと呼ばれる主に文字を修飾するものを使用し記述する。
`<タグ名>...</タグ名>`の形式で使用することが多い。

### JavaScript を体験する

JavaScript を一番簡単に動作させることができる環境は、Webブラウザです。

WebブラウザがWebページを表示する際、 HTML という、Webページの大まかな構造を決定する言語で記述されたファイルを読み込みます。

今回は、 HTML の中に JavaScript を埋め込むという方式で JavaScript を動かします。

<CaptionImage src="/attachments/meister/js/2024/1/javascript.webp" caption="執筆時点での Google Chrome における JavaScript に関する設定。" />

{/*
<Info>
自分のコンピューターにないWebサイトにアクセスするには、 URL (Uniform Resource Locator) という文字列が必要です。

URLは、インターネット上で一意なファイルの位置です。
少し詳しく解説すると、URL にはどのサーバーのどのフォルダにあるファイル、という情報が含まれています。

---

例えば、 `https://docs.mirrei.dev/meister/js/2024/1` という URL において、指定されているのは以下の情報です。

| 種類 | 内容 |
| --- | --- |
| 接続方式 | `https` (暗号化された接続) |
| サーバー | `docs.mirrei.dev` |
| ファイル | `/meister/js/2024/1` |
</Info>
*/}

それでは、任意のエディタを起動し、以下の内容を貼り付けてください。

```html
<script>
    document.write("Hello World!");
</script>
```

その後、ファイルを保存します。
HTML ファイルであることを示す `.html` という拡張子で保存してください。

<Info>
拡張子とは、ファイル名の末尾に特定の文字列を入れ、そのファイルの中身の情報の種類を大まかに決めておくものです。

この場合、 `.html` という拡張子を使用する必要があります。
`meister.html` や `test.html` などのファイル名が有効です。
</Info>

保存したら、保存したファイルをダブルクリックしてみましょう。

デフォルトの設定ではWebブラウザが開くと思います。
開かなければ、Webブラウザを開いてドラッグアンドドロップしてみてください。

画面に「Hello World!」と表示されていたら成功です！

<CaptionImage src="/attachments/meister/js/2024/1/html-sample.webp" caption="Visual Studio Code と Google Chrome を使用して、「Hello World!」を表示させている画面。" />

### JavaScript の動かし方を理解する

先ほどの文字列が書き込まれたファイルをWebブラウザで読み込ませることによって、いったい何を行ったのでしょうか。

Webブラウザは、先ほどの文字列を HTML として解釈します。
HTML は、タグと呼ばれる文章の飾りのようなものを`<タグ名>...</タグ名>`という記法で記述し構成されています。

例えば、1行目と3行目に`<script>`と`</script>`という文字があります。
`script`というタグは、 JavaScript を HTML 内に埋め込むことができるタグです。

先ほど「HTML の中に JavaScript を埋め込むという方式で JavaScript を動かす」と書いたのがお分かりいただけたでしょうか。

これで、 JavaScript を動かすことができました。

<Info>
ここまでで`<script>`タグについての説明は以上となりましたので、講義において前後の`<script>`と`</script>`は省略します。
</Info>

### JavaScript を動かす

チュートリアルとして、「Hello World!」を別の文字に変えてみましょう。

エディタに戻って、 JavaScript が書かれた部分を見てください。
先ほど解説したように、`<script>`と`</script>`で囲まれた部分、つまり2行目に JavaScript コードが記述されています。

特段難しいことはありません。今回は命令が1行しかありませんので、見るのは1行のみです。
ここの「Hello World!」の部分を好きな文字に変えてみましょう。

保存し、ブラウザを再読み込みしてみましょう。文字が変わっていたら成功です:tada:

<Tips>
この動作はショートカットキーを使用すると素早く完了することができます。
例えば Windows の場合、保存は<kbd>Ctrl</kbd> + <kbd>S</kbd>、再読み込みは <kbd>Ctrl</kbd> + <kbd>R</kbd> です。

macOS の場合は、<kbd>Ctrl</kbd>を<kbd>Command</kbd>に変えればそのままこのショートカットは使用できます。
</Tips>

### document.write について

先ほどから `document.write` という文字が出現していますが、これはどういう意味なのでしょうか。

直訳すると「文書.書き込み」となります。
その名の通り、文書（つまり、Webページ）に対して JavaScript から書き込みを行う命令です。

今後学習しますが、 JavaScript においては命令のことを関数と呼びます。
`document.write` は、その中でもWebブラウザで実行される JavaScript が標準で呼び出すことのできる関数です。

## 四則演算を行う

では、いよいよプログラミングらしきことをしていきましょう。

まずは、プログラムに計算を行わせます。

最初は<math aria-label="1+1"><mn>1</mn><mo>+</mo><mn>1</mn></math>を計算させましょう。

```js
document.write(1 + 1);
```

<CaptionImage src="/attachments/meister/js/2024/1/calculation-correct.webp" caption="1 + 1 を計算し、画面に出力する例。" />

<Caution>
**よくある例: 文字列リテラルになっている**
<CaptionImage src="/attachments/meister/js/2024/1/calculation-riteral-wrong.webp" caption="1 + 1 を文字列リテラルとして記述してしまっている例。" />

`document.write("1 + 1");` では、「1 + 1」と出力されます。どうしてでしょうか。

JavaScript、その他の言語においても、多くの言語に「文字列は `"`（ダブルクォーテーション） で囲む」というルールが存在します。

今回の間違いでも例に漏れず、ダブルクォーテーションで囲ってしまっています。
つまり、「`1 + 1` という**文字列**を表示する」という命令になっているのです。

JavaScript に計算や評価をさせたい場合は、`"`（ダブルクォーテーション）を外す必要があります。
</Caution>

<Tips>
文末にある `;`（セミコロン） はプログラムの切れ目です。
JavaScript においては、これを外してもプログラムとしては動作します。

しかし、コードの可読性の観点からつけておくことをおすすめします。
</Tips>

### 演算子一覧

応用として、`1 + 1` 以外の計算をさせてみましょう。

JavaScript では代表的に以下の演算子が使用できます。

| 演算子 | 意味 |
| - | - |
| + | 加算（足し算） |
| - | 減算（引き算） |
| * | 乗算（掛け算） |
| / | 除算（割り算） |
| % | 剰余（割り算の余り） |
| ** | べき乗 |

この演算子を使用し、いろいろな計算をするプログラムを作ってみましょう。

<Tips>
数学において、計算順序が低い演算を優先させたいときは `()` を使用します。
例えば、<math aria-label="(3+5)×2"><mo>(</mo><mn>3</mn><mo>+</mo><mn>5</mn><mo>)</mo><mo>&times;</mo><mn>2</mn></math> などが挙げられます。

JavaScript においても、そのままかっこを使用できます。
例えば、上記の例であれば `(3 + 5) * 2` と記述できます。
ただし、`()` は全角ではなく半角を使用しなければならないことに注意してください。
</Tips>

## 命令を増やす

先ほど演算をしましたが、一度に一つしか演算できないわけではありません。

`document.write` の行を複数に増やせば、複数回の演算と画面の描画を行うことができます。

```js
document.write(1 * 1);
document.write(1 * 2);
document.write(1 * 3);
```

<CaptionImage src="/attachments/meister/js/2024/1/multiple-line-without-br.webp" caption="document.write の呼び出しを複数に増やした例。" />

`123` という結果が出力されました。これは異常ではなく、正常な動作です。

### 改行を入れる

理由は、改行を示す文字が挿入されていないからです。`1`、`2`、`3`という演算の結果を改行を入れずに書き込んだ結果であるということです。

では、各行の間にそれぞれ改行を示す文字を入れてみましょう。改行を示す文字は HTML において `<br />` です。

文字、つまり**文字列**を出力するには、「[四則演算を行う](#四則演算を行う)」で触れている通り、`"`（ダブルクォーテーション）で囲う必要があります。

```js
document.write(1 * 1);
document.write("<br />");
document.write(1 * 2);
document.write("<br />");
document.write(1 * 3);
```

<CaptionImage src="/attachments/meister/js/2024/1/multiple-line.webp" caption="<br /> を入れた例。" />

<Tips>
「[イントロダクション > JavaScript の動かし方を理解する](#JavaScript の動かし方を理解する)」で HTML のタグに関する説明をしました。 `<br />` もタグの一種です。

HTML ではこのように、タグを閉じることを示す `</タグ名>` を必要としない、あるいは省略してもいいタグが存在します。

---

[開始と終了を同時に記述した `<br />` という記法のほうが正式な書き方であるみたいな風潮がある](https://developer.mozilla.org/ja/docs/Web/HTML/Element/br)気がします。
もし知っていたら教えていただけるとありがたいです。
HTML歴12年なんですけどね…
</Tips>

## 変数を使用する

変数とは、一時的に値を保存、記憶しておく場所です。

<Info>
変数がないと、例えば「計算結果を2回表示するプログラム」を作る際には、2回計算をしなくてはいけなくなります。以下がそのコード例です。

```js
document.write(3 * 5);
document.write(3 * 5);
```

このコードでは、<math aria-label="3×5"><mn>3</mn><mo>&times;</mo><mn>5</mn></math>を2回計算しています。

コンピューターは動作があまりにも高速なため、2回程度では全く問題になりませんが、これが1億回…といったレベルで繰り返されていたら無駄な計算が増えてしまいます。

1億回も表示することは通常ありませんが、「1億回別々の計算をするが、それぞれの計算式には前提として事前に計算できる同じ値を使う」とかだったらあり得るシチュエーションです。
</Info>

変数には、**宣言**を行った後、**代入**と**参照**という2通りの使い方ができます。
代入は変数に値を入れることです。
参照は、変数から値を読み込むことです。読み込んだ後、プログラムで使用したりします。

変数は、自分でその変数の名前を決め、宣言することで使用可能になります。
宣言せずに使用（代入もしくは参照）すると、たいていの場合エラーが発生します。

今回は、`hensuu` という変数を宣言し、使用することにします。
```js
var hensuu;
```

この変数に値を代入するには、以下のように記述します。
```js
hensuu = 1;
```
```js
hensuu = 0.1;
```
```js
hensuu = "任意の文字列";
```
```js
hensuu = 1 + 2 + 3 + 4 + 5;
```

<Tips>
JavaScript では、型の概念がありません。
そのため、数値を入れた後に文字列を入れることも許可されています。

しかし、型の概念がないことはエラーの原因になりえます。
大規模開発の際は、 TypeScript という JavaScript の派生言語であり、トランスパイルすることで JavaScript コードとして実行できる言語を使用するとスムーズに開発が進行します。

[TypeScript については、コラムで説明しています。](/meister/js/2024/column/2)
</Tips>

また、宣言と同時に値を代入する（一般的に、初期化と呼ばれる）ことができます。
```js
var hensuu = "宣言しつつ、この文字列を hensuu に代入";
```

<Tips>
JavaScript には、 `let` や `const` など、 `var` 以外の変数の宣言方法もあります。

`let` は `var` と違い再宣言（もう一度 `var hensuu = ...;` を記述すること）が不可能であること、 `const` は再代入が不可能であることが特徴です。

主観ですが、現在では JavaScript で `var` を使用するプログラマーも少なくなっているように感じます。
</Tips>

<Tips>
JavaScript では、変数や関数の名前に日本語や絵文字をつけることができます。
プログラミング経験者からすると、「マジか…」という感想を抱くかと思います。

そのため、この講義では意図して変数名の制約に関する記述をしておりません。
</Tips>

これを応用することで、例えば税率の計算の修正を手軽に行うことができます。

100円の商品の消費税（ここでは10%とする）を計算するプログラムは以下の通りです。

```js
var tax_rate = 0.1;

document.write(100 * tax_rate);
```

このように変数を利用することで、プログラムの作成を効果的に進めることができます。

## インクリメント・デクリメント

変数を 1 加算することを「インクリメント」、 1 減算することを「デクリメント」と呼びます。

使用する場所は多いとは言えませんが、第2回で説明するfor文などで主に使用されます。

例えば、`hensuu` をインクリメントするには以下のように記述します。

```js
hensuu++;
```

また、デクリメントを行うには以下のように記述します。

```js
hensuu--;
```
